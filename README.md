# Desafío Grid

Proyecto de CSS avanzado utilizando Grid Layout para mostrar una tienda de merchandising de Tim Burton.

## Enlace desplegado

https://fabianaromeromarcel.github.io/Desafio-grid/

## Archivos principales

- `index.html`
- `assets/css/style.css`

## Descripción

Esta página utiliza CSS Grid para estructurar la página en `header`, `nav`, `main` y `footer`, y muestra tarjetas de productos con imágenes y botones de compra.
